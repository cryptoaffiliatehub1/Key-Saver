## Features and where they live

1. **FFmpeg grain**: `ffmpeg_params=["-vf", "noise=alls=10:allf=t"]` in `viral_engine.py` `write_videofile` call. MoviePy 2.x accepts this as a list; do NOT use `output_params`.

2. **Persistent clip tracker**: `asset_tracker.py` — SQLite at `data/asset_tracker.db`. `is_used(source, id)` and `mark_used(source, id)` called in both `download_pexels_clips` and `_download_pixabay_clips` inside `viral_engine.py`. Sources are `"pexels"` and `"pixabay"` (lowercase strings, must stay consistent).

3. **MiniMax quality modifiers**: `minimax_engine.py` — `build_prompt(user_prompt)` appends cinematic quality modifiers and negative constraints. No MiniMax video generation existed before; this module adds it. Key rotation: MINIMAX_KEY_1/2/3.

4. **SEO metadata engine**: `seo_oracle.py` — `generate_seo_metadata(script, seed)` returns `(description_str, hashtags_list)`. Called from `generate_viral_script` in `viral_engine.py`. Titles now hard-clamped to 60 chars. Description is 2-3 sentences + 3-4 `#hashtags` appended to full_description.

5. **Phonetic correction map**: In `build_short()` caption block in `viral_engine.py`. `_PHONETIC_MAP` dict defined inline; `_correct_word()` applied to every raw word before ALL-CAPS rendering.

6. **Caption safe zone**: Already in place — 900px width, y_pos = TARGET_H * 0.65, pill background, 4px stroke.

7. **Dashboard fidelity checklist**: In `main.py` template, shows all 7 features with green checkmarks when job state == 'done'.

## Why
**Why:** These were the master-command requirements from the user. The grain filter must come last in the ffmpeg pipeline (MoviePy adds it). The asset_tracker must persist across process restarts (SQLite, not in-memory set). The SEO metadata replaces the LLM's own description field — the Gemini VIRAL_PROMPT no longer emits `description`; that field is now generated by `seo_oracle.generate_seo_metadata()`.

## How to apply
- Adding new clip sources: call `asset_tracker.is_used(source, id)` before download and `asset_tracker.mark_used(source, id)` after successful save.
- Extending phonetic map: edit `_PHONETIC_MAP` dict in `build_short()`.
- Extending SEO: edit `METADATA_PROMPT` in `seo_oracle.py`.
- Extending MiniMax quality modifiers: edit `QUALITY_MODIFIERS` and `NEGATIVE_CONSTRAINTS` constants in `minimax_engine.py`.
